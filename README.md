# 📖 Leitor Adaptativo - Acessibilidade na Leitura (ODS 10)

Projeto de extensão universitária desenvolvido para o curso de Engenharia da Computação, focado em reduzir a desigualdade no acesso à informação através da técnica de leitura adaptativa.
