# 📖 Leitor Adaptativo - Acessibilidade na Leitura (ODS 10)

Projeto de extensão desenvolvido para o curso de Engenharia da Computação da faculdade Centro Universitário Unibta, com base no Objetivo de Desenvolvimento Sustentável 10 - Redução das Desigualdades. 

Nosso projeto visa a inclusão no acesso à informação através da técnica de leitura adaptativa.

### 🎯 Objetivo
Auxiliar pessoas com dificuldades de leitura, TDAH, dislexia ou fadiga visual a processarem conteúdos textuais digitais com maior fluidez e menor esforço cognitivo.
